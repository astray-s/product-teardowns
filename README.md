# Product Teardowns

A collection of product teardowns and PM case studies — analyzing apps through a user research lens.

Each teardown follows the same framework:
- **Problem** — what user problem the product solves
- **What works** — 2–3 things done well, and why
- **What I'd change** — 2–3 specific critiques with reasoning
- **Success metrics** — how I'd measure the impact of a proposed change
- **PM insight** — one takeaway about good product thinking
